## 0. 模体、狭缝与扫描模式统一约定

### 0.1 模体与缺陷编号

主实验统一采用空气缺陷，默认缺陷尺寸为：

\[
10\,\mathrm{mm}\times10\,\mathrm{mm}\times10\,\mathrm{mm}
\]

主实验的缺陷中心均布置在当前背散射重点探测厚度 \(0\sim100\ \mathrm{mm}\) 内。推荐模体编号与缺陷设置如下：

| 模体编号 | 类型 | 缺陷中心深度 \(z_c\) | 横向位置 | 缺陷尺寸 | 用途 |
|---|---|---:|---|---|---|
| P0 | 均匀 PMMA | — | — | — | 响应核标定、背景参考 |
| P1 | on-axis 空气缺陷 | 15 mm | \((x_0,y_0)\) | \(10\times10\times10\ \mathrm{mm^3}\) | 浅层缺陷 |
| P2 | on-axis 空气缺陷 | 30 mm | \((x_0,y_0)\) | \(10\times10\times10\ \mathrm{mm^3}\) | 浅中层缺陷 |
| P3 | on-axis 空气缺陷 | 45 mm | \((x_0,y_0)\) | \(10\times10\times10\ \mathrm{mm^3}\) | 中浅层缺陷 |
| P4 | on-axis 空气缺陷 | 60 mm | \((x_0,y_0)\) | \(10\times10\times10\ \mathrm{mm^3}\) | 中层代表缺陷 |
| P5 | on-axis 空气缺陷 | 75 mm | \((x_0,y_0)\) | \(10\times10\times10\ \mathrm{mm^3}\) | 中深层缺陷 |
| P6 | on-axis 空气缺陷 | 90 mm | \((x_0,y_0)\) | \(10\times10\times10\ \mathrm{mm^3}\) | 深层边界缺陷 |
| P4_off | off-axis 空气缺陷 | 60 mm | 位于 S4 acceptance volume 内，偏离入射束主轴；建议 \((x_0+10\sim15\ \mathrm{mm},y_0)\) | \(10\times10\times10\ \mathrm{mm^3}\) | acceptance volume 边界验证 |

说明：

1. P1–P6 用于主实验的深度响应、深度匹配与机制验证。
2. P4 作为中等深度代表缺陷，适合用于 E2、E3、E4、E7 的机制分析。
3. P4_off 与 P4 保持相同深度和尺寸，仅改变横向位置，用于 E6 中的 off-axis 对照。

### 0.2 狭缝编号与目标响应深度

狭缝编号与目标缺陷深度一一对应，即：

\[
S_j \leftrightarrow P_j
\]

其中 \(S_j\) 的主响应深度覆盖 \(P_j\) 的缺陷中心。推荐狭缝编号如下：

| 狭缝编号 | 目标响应深度 | 对应缺陷模体 | 说明 |
|---|---:|---|---|
| S1 | 15 mm 左右 | P1 | 浅层响应通道 |
| S2 | 30 mm 左右 | P2 | 浅中层响应通道 |
| S3 | 45 mm 左右 | P3 | 中浅层响应通道 |
| S4 | 60 mm 左右 | P4 | 中层响应通道 |
| S5 | 75 mm 左右 | P5 | 中深层响应通道 |
| S6 | 90 mm 左右 | P6 | 深层边界响应通道 |

说明：表中“目标响应深度”为设计目标，实际峰值位置应以 E1 中的均匀模体深度响应核标定结果为准。

### 0.3 两种扫描模式

仿真统一采用两类扫描模式：`center` 与 `grid`。

#### center 模式

center 模式下，入射束对准参考中心位置：

\[
p_0=(x_0,y_0)
\]

对于缺陷模体，center 模式表示入射束对准缺陷中心；对于均匀模体 P0，表示对准参考中心位置。该模式主要用于：

- 深度响应核标定；
- 源项扰动统计；
- 目标区/非目标区分解；
- 小缺陷条件下的机制验证。

#### grid 模式

grid 模式下，在参考中心附近施加不同 \(x/y\) offset：

\[
p_{ab}=(x_0+\Delta x_a,\ y_0+\Delta y_b)
\]

每个 pose 记录一个探测计数：

\[
N_{k,p_{ab}}
\]

并构建二维响应图：

\[
I_k(a,b)=N_{k,p_{ab}}
\]

或归一化形式：

\[
I_k^{norm}(a,b)=\frac{N_{k,p_{ab}}}{N_{0,k,p_{ab}}}
\]

其中 \(N_{0,k,p_{ab}}\) 为 P0 在相同 pose 和相同狭缝条件下的计数。grid 模式主要用于：

- 生成二维计数热力图；
- 评价缺陷中心、缺陷边缘与背景区域的图像响应；
- 计算 contrast、CNR、背景方差等图像质量指标。

推荐 grid 采样范围如下：

| 项目 | 建议值 |
|---|---|
| 主网格 | \(7\times7\) |
| offset 集合 | \(\{-15,-10,-5,0,5,10,15\}\ \mathrm{mm}\) |
| 备选简化网格 | \(5\times5\) |
| 简化 offset 集合 | \(\{-15,-5,0,5,15\}\ \mathrm{mm}\) |

其中 \(\pm5\ \mathrm{mm}\) 覆盖缺陷边缘，\(\pm10\ \mathrm{mm}\) 与 \(\pm15\ \mathrm{mm}\) 主要用于采集邻近背景和远端背景。

## 2. 实验的具体设计要点

### E1 均匀模体多狭缝深度响应核验证

| 项目 | 设计要点 |
|---|---|
| 实验目的 | 建立 S1–S6 的系统响应基础，证明狭缝准直提供的是有限宽度深度响应权重，而非理想深度切片。 |
| 模体设置 | 采用 P0 均匀 PMMA 模体，不设置缺陷。 |
| 扫描模式 | center。E1 不需要 grid 扫描。 |
| 扫描条件 | S1–S6 分别运行；入射能量、源强、笔形束位置、探测平面、统计粒子数保持一致。 |
| 事件分类 | total、k1、ms；k1 表示一次散射后被探测的事件，ms 表示多重散射后被探测的事件。 |
| 统计对象 | `first_scatter_z` 分布；各 slit 下的深度响应峰值、均值、标准差、FWHM、80% 积分响应区间、相邻核重叠系数。 |
| 归一化方式 | 每个 slit 的 `first_scatter_z` 分布可先按总探测计数归一化，用于比较响应核形状；再保留原始计数用于评价统计可靠性。 |
| 输出要求 | 给出 S1–S6 的归一化响应曲线和响应参数表。曲线中应标注峰值深度、FWHM 区间和对应缺陷中心深度。 |
| 论文作用 | 为后续 \(K_k(i)\) 的空间选择性提供仿真依据，并为 E5 的深度匹配实验提供基准响应核。 |

建议使用以下响应核参数：

\[
\bar z_k=\frac{\sum_j z_j n_k(z_j)}{\sum_j n_k(z_j)}
\]

\[
\sigma_{z,k}=\left[\frac{\sum_j (z_j-\bar z_k)^2 n_k(z_j)}{\sum_j n_k(z_j)}\right]^{1/2}
\]

建议补充相邻核重叠系数：

\[
O_{j,j+1}=\frac{\int \min[K_j(z),K_{j+1}(z)]\,dz}{\int K_j(z)\,dz}
\]

其中 \(n_k(z_j)\) 为第 \(k\) 个 slit 条件下第 \(j\) 个深度 bin 的探测事件数。

### E2 缺陷源项扰动验证

| 项目 | 设计要点 |
|---|---|
| 实验目的 | 验证 P4 空气缺陷导致缺陷区局部散射源项下降，并引起沿笔形束路径的源项重分布。 |
| 模体设置 | P0 均匀 PMMA；P4 中层空气缺陷，缺陷中心深度 60 mm，尺寸 \(10\times10\times10\ \mathrm{mm^3}\)。 |
| 扫描模式 | center。入射束对准缺陷中心。 |
| 扫描条件 | 重点采用 S4；也可同步保留 S3/S5 数据，用于检验匹配与邻近串扰。 |
| 分区方式 | 核心目标区可先按缺陷实际厚度取 \(55\le z<65\ \mathrm{mm}\)；扩展目标敏感区可按 E1 得到的 S4 响应核 FWHM 确定。前方和后方区域相对于该目标敏感区定义。 |
| 统计对象 | total、k1、ms 的三段计数；P4/P0 比值；\(\Delta N=N_{P4}-N_{P0}\)；相对变化；泊松 z-score。 |
| 判据 | 目标区计数显著下降；前方变化处于统计涨落量级；后方计数出现聚合意义上的抬升。 |
| 输出要求 | 三段分区统计表应分别列出 total、k1、ms；图中需同时展示原始计数和 P4/P0 比值。 |
| 论文作用 | 支撑 \(\Delta q_i<0\) 的源项扰动解释，并为 E3、E4 的目标区/非目标区分解提供基础。 |

泊松显著性可采用：

\[
z=\frac{N_{P4}-N_{P0}}{\sqrt{N_{P4}+N_{P0}}}
\]

该式用于同等模拟历史数条件下的两组独立计数近似比较。若 P0/P4 模拟历史数不同，应先按入射粒子数或源强归一化后再计算不确定度。

### E3 目标区多重散射结构响应验证

| 项目 | 设计要点 |
|---|---|
| 实验目的 | 直接验证 first scatter 位于目标区的多重散射事件是否随空气缺陷发生结构性响应。 |
| 模体设置 | P0 与 P4。 |
| 扫描模式 | center。 |
| 目标区定义 | 基础定义：\(\Omega_T=\{55\le first\_scatter\_z<65\ \text{mm}\}\)。扩展定义：以 E1 得到的 S4 响应核 FWHM 或响应权重大于阈值的区域定义 \(\Omega_T\)。 |
| 非目标区定义 | \(\Omega_N=\Omega\setminus\Omega_T\)，可进一步拆分为 \(\Omega_{front}\) 和 \(\Omega_{behind}\)。 |
| 事件分类 | k1 与 ms 均按 first scatter 位置归入目标区或非目标区。 |
| 统计对象 | \(N_T^{(1)}\)、\(N_T^{(m)}\)、\(N_N^{(1)}\)、\(N_N^{(m)}\)；各项在 P0/P4 间的绝对变化、相对变化和显著性。 |
| 核心判据 | P4 中 \(N_T^{(m)}\) 显著低于 P0，且变化方向与 \(N_T^{(1)}\) 一致。 |
| 输出要求 | 四象限分解图应同时展示 P0 与 P4；目标区 ms 的变化应单独给出统计显著性。 |
| 论文作用 | 作为“目标敏感区域内多重散射事件可携带缺陷结构响应”的核心证据。 |

四项分解建议直接写为：

\[
N_k=N_{T,k}^{(1)}+N_{T,k}^{(m)}+N_{N,k}^{(1)}+N_{N,k}^{(m)}+\eta_k
\]

并分别统计：

\[
N_{T,k}^{(m)}=\sum_{i\in\Omega_T}q_iK_k^{(m)}(i)
\]

\[
N_{N,k}^{(m)}=\sum_{i\in\Omega_N}q_iK_k^{(m)}(i)
\]

### E4 非目标多重散射背景来源分解

| 项目 | 设计要点 |
|---|---|
| 实验目的 | 将 ms 背景拆分为不同 first-scatter 来源分量，明确目标相关 ms 与非目标 ms 的贡献差异。 |
| 模体设置 | P0 与 P4；重点分析 S4。 |
| 扫描模式 | center 为主；若需要展示 ms 分量二维图像，可增加一个代表性 grid 扫描。 |
| 分量定义 | ms_front：目标敏感区前方 first scatter 事件；ms_target：first scatter 落在 \(\Omega_T\) 内的 ms 事件；ms_behind：目标敏感区后方 first scatter 事件。 |
| 统计对象 | 三类 ms 分量的计数、占比、P4/P0 比值、\(\Delta N/N_0\)、泊松 z-score。 |
| 辅助统计 | `last_scatter_z`、`last_scatter_y`、`scatter_count_total`、`det_energy`、轨迹在 x–z 平面的投影分布。 |
| 图像指标 | 若采用 grid，则分别重建 ms_front、ms_target、ms_behind 图像，计算缺陷 contrast、CNR、背景方差。 |
| 判据 | ms_target 具有显著缺陷响应；ms_front 对缺陷不敏感或变化较弱；ms_behind 与通量重标定或深部响应有关。 |
| 输出要求 | 使用堆叠柱状图展示 ms 各来源占比；若补充图像展示，应单独给出三类 ms 分量对缺陷可见性的贡献。 |
| 论文作用 | 支撑多重散射背景的来源机制，即多重散射背景主要来自非目标区域源项混入。 |

图像质量指标建议采用：

\[
CNR=\frac{|\mu_D-\mu_B|}{\sqrt{\sigma_D^2+\sigma_B^2}}
\]

\[
Contrast=\frac{\mu_B-\mu_D}{\mu_B}
\]

其中 \(\mu_D\)、\(\sigma_D\) 为缺陷区图像均值和标准差，\(\mu_B\)、\(\sigma_B\) 为邻近背景区图像均值和标准差。

### E5 缺陷深度与狭缝响应匹配实验

| 项目 | 设计要点 |
|---|---|
| 实验目的 | 验证缺陷可见性取决于缺陷深度与 slit-dependent response \(K_k(i)\) 的匹配程度。 |
| 模体设置 | 设置 P1–P6 六个深度空气缺陷。缺陷材料、尺寸、横向位置保持一致，仅改变深度。 |
| 扫描模式 | 采用两层设计：center 用于完整运行 \(P_j\times S_k\) 组合；grid 仅用于代表性匹配/非匹配组合的二维图像展示。 |
| 扫描条件 | 对每个缺陷模体分别采用 S1–S6 成像。 |
| 控制变量 | 入射能量、笔形束尺寸、扫描步长、粒子数、图像重建 bin 尺寸保持一致。 |
| 统计对象 | 每个缺陷深度在每个 slit 下的 total/k1/ms 计数变化、\(\Delta N/N_0\)、目标响应比 \(R_k\)；代表性 grid 图像的 contrast、CNR。 |
| 核心分析 | 优先使用 center 模式得到完整的“缺陷深度 × slit 条件”响应矩阵；再选取少量代表组合进行二维成像，例如 P1–S1、P4–S4、P6–S6 以及 1–2 组非匹配对照。 |
| 判据 | 缺陷深度落入某一 slit 主要响应区时，该 slit 的 \(\Delta N/N_0\)、\(R_k\) 和代表性图像 CNR 较高。 |
| 输出要求 | 响应矩阵用于展示匹配关系；图像对比需采用统一灰度范围或统一归一化策略。 |
| 论文作用 | 将源项响应框架与深度选择成像能力建立联系，证明图像响应由 \(q_i\) 与 \(K_k(i)\) 共同决定。 |

目标响应比可写为：

\[
R_k=\frac{\sum_{i\in\Omega_T}q_i\left[K_k^{(1)}(i)+K_k^{(m)}(i)\right]}{\sum_{i\in\Omega_N}q_i\left[K_k^{(1)}(i)+K_k^{(m)}(i)\right]+\eta_k}
\]

该指标可使用蒙特卡罗事件真值进行估计，用于评价不同 slit 对目标源项的选择性。

### E6 acceptance volume 边界验证

| 项目 | 设计要点 |
|---|---|
| 实验目的 | 限定“acceptance volume 内结构直接投影”解释，明确当前结构响应主要来自入射束路径上的 first-scatter source term 扰动。 |
| 模体设置 | P0 均匀模体；P4 缺陷位于入射笔形束路径和 S4 响应敏感深度；P4_off 缺陷位于 S4 acceptance volume 内但偏离入射笔形束路径。 |
| 扫描模式 | center。 |
| 扫描条件 | 重点采用 S4；必要时可补充 S3/S5 作为辅助对照。 |
| 统计对象 | total/k1/ms 总计数变化；`first_scatter_z` 分布；缺陷区域 first scatter 计数；ms 事件路径分布。 |
| 判据 | P4_off 相对 P0 的变化显著弱于 P4；P4_off 对入射束路径上的 first scatter 分布影响较小。 |
| 输出要求 | 同时展示 P0/P4/P4_off 的计数变化和 `first_scatter_z` 分布；应加入几何示意图区分入射束路径与 acceptance volume。 |
| 论文作用 | 排除将 ms 简化为 acceptance volume 内结构直接积分投影的强解释，强化源项归属判据。 |

表述边界应保持谨慎：P4_off 结果用于说明“当前几何和缺陷条件下，偏离入射束路径的结构响应较弱”。该结论仅适用于当前几何和缺陷条件。

### E7 小缺陷条件下 \(\Delta q\) 与 \(\Delta K\) 相对贡献验证

| 项目 | 设计要点 |
|---|---|
| 实验目的 | 验证小缺陷条件下探测计数变化是否主要由缺陷区局部源项变化贡献，并给出近似适用范围。 |
| 模体设置 | 固定缺陷中心深度于 P4 位置，并采用 S4；建议尺寸序列：\(5\times5\times5\)、\(10\times10\times10\)、\(15\times15\times10\)、\(20\times20\times10\ \mathrm{mm^3}\)。 |
| 扫描模式 | center。 |
| 固定变量 | 缺陷中心深度、材料类型、扫描几何、入射能量、粒子数保持一致。 |
| 统计对象 | 缺陷区 first scatter 缺失量；后方 first scatter 抬升量；total/k1/ms 的 \(\Delta N\)；目标区与非目标区贡献。 |
| 核心分析 | 比较 \(\Delta N\) 与缺陷区 first scatter 缺失量之间的线性相关性；观察缺陷尺寸增大后后方通量重标定是否增强。 |
| 判据 | 小尺寸范围内 \(\Delta N\) 与目标区源项缺失近似线性；当后方抬升和非目标贡献明显增强时，小缺陷近似需要改用完整表达。 |
| 输出要求 | 给出缺陷尺寸—响应曲线、源项缺失—计数变化散点图、近似适用范围表。 |
| 论文作用 | 为小缺陷推导提供定量支撑，并回答审稿中可能出现的适用范围问题。 |

完整扰动表达建议保留为：

\[
\Delta N_k=
\sum_i \Delta q_i\left[K_k^{(1)}(i)+K_k^{(m)}(i)\right]
+
\sum_i q_i^0\left[\Delta K_k^{(1)}(i)+\Delta K_k^{(m)}(i)\right]
\]

小缺陷近似成立时可写为：

\[
\Delta N_k\approx
\sum_{i\in D}\Delta q_i\left[K_k^{(1)}(i)+K_k^{(m)}(i)\right]
\]

建议引入一个经验比例指标：

\[
\rho_D=\frac{|\Delta N_{target}|}{|\Delta N_{target}|+|\Delta N_{behind}|+|\Delta N_{front}|}
\]

当 \(\rho_D\) 接近 1 时，目标区源项扰动占主导；当 \(\rho_D\) 明显下降时，非目标贡献和传播扰动不可忽略。

### E8 非目标源项抑制与图像质量提升验证

| 项目 | 设计要点 |
|---|---|
| 实验目的 | 验证图像质量优化目标应从单纯按散射阶次筛除转向非目标源项响应抑制。 |
| 输入数据 | P0 标定数据、代表性缺陷数据、E3/E4 得到的目标区/非目标区事件分解。主方案建议采用 P4–S4 的 grid 图像，辅助方案可增加 P6–S6。 |
| 扫描模式 | grid。E8 需要生成二维响应图像。 |
| grid 设置 | 推荐采用 \(7\times7\) 网格，offset 集合为 \(\{-15,-10,-5,0,5,10,15\}\ \mathrm{mm}\)。 |
| 方法 A | 前方稳定背景扣除：利用 P0 或同批次均匀模体估计 \(N_{front}^{(m)}\)，对缺陷图像进行扣除或归一化。 |
| 方法 B | 后方通量重标定：根据后方 P4/P0 或 P6/P0 比值估计，对深部源项抬升进行归一化。 |
| 方法 C | 源项相关加权：利用 MC 事件真值对目标区事件赋较高权重，对非目标区 ms 事件赋较低权重，作为机制验证的上限分析。 |
| 对照方案 | 原始 total 图像、k1 图像、ms 图像、直接剔除 ms 的图像、非目标源项抑制后的图像。 |
| 评价指标 | 缺陷 contrast、CNR、背景均匀性、背景方差、目标响应比 \(R_k\)、统计方差放大因子。 |
| 判据 | 非目标源项抑制后 CNR 和背景均匀性提升；目标区结构响应保留；扣除引入的方差增量可控。 |
| 输出要求 | 图像对比必须采用一致的 ROI 定义；CNR、contrast 和背景方差应在同一表中列出。 |
| 论文作用 | 将机制解释转化为可操作的图像质量优化策略，增强论文完整性和应用价值。 |

统计方差放大需要单独检查。若采用背景扣除：

\[
I_{corr}=I_{meas}-\alpha I_{cal}
\]

则近似有：

\[
\sigma_{corr}^2=\sigma_{meas}^2+\alpha^2\sigma_{cal}^2
\]

因此 E8 不能只报告 CNR 提升，还应报告扣除前后的背景方差变化。
