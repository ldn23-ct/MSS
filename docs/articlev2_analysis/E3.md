# E3：基于 source truth 的成像作用与理想基准

## 状态与定位

E3 待设计和实现。它位于 E1 系统基线与 E2 缺陷响应机制之后，用于评价 source-region information 对二维成像的潜在价值，而不重复 E2 已完成的 center front/target/behind decomposition。

## 保留边界

- 使用 grid 条件和 Monte Carlo source truth；
- grid target-source event 必须由 first-scatter position 是否落入缺陷三维体积定义，不能只使用目标深度层；
- 后续可比较保留、去除或理想识别不同 source-conditioned MS contribution 对图像质量的作用；
- oracle/ideal 结果不等同于已经提出可部署的输运校正算法。

具体图像组合、事件选择策略、Contrast/CNR 指标、输入条件和验收合同尚未冻结。E3 当前没有可执行入口，也不得复用 E2 输出冒充 E3 结果。
