# E3：基于 source truth 的成像作用与理想基准

## 状态与数据边界

`results/articlev3_merged/events/valid/grid/` 已包含 P0/P1–P6 的全部 matched 主网格，八个条件各 81 pose、每 pose 100M histories。`run_core.py` 已据此生成 E3-F1～F5 和 E3-T1～T3，并通过固定 5 PNG + 3 CSV 合同。

当前唯一缺项是 P4–S4 所需的 55 mm 均匀 PMMA 前层 slab 参考 81 位姿。因此 E3-F6/E3-T4 不生成、不替代；原 `run.py` 保持严格完整入口，待 slab 导入后再发布 6 PNG + 4 CSV。

该参考模体和远端 8 worker × 6 threads 仿真命令已冻结，见 [E3_slab_remote_run.md](E3_slab_remote_run.md)。远端只需回传独立 raw campaign；在数据导回前，本节完成状态保持不变。

脚本不提供 partial/preview 模式。任一条件缺位姿、重复坐标、坐标越界、metadata 不一致或 slab provenance 不合格时，均在创建输出前失败；不得补零、插值或使用 center 数据代替 grid 数据。

## 输入与事件选择

- 主输入为 `results/articlev3_merged/events/valid/grid/` 和通过审核的 `condition_inventory.csv`；要求 P0 与 P1–P6 的 matched profile 全部具有 9×9 网格。
- 每个 pose 读取 `events_valid.csv` 和同目录 `metadata.yaml`，要求 560 keV、grid mode、正确 phantom/profile、实际扫描坐标及同一条件内一致的入射历史数。
- 对 matched slit 同时要求 recorded `slit_label` 正确，并叠加随 pose 平移的闭区间 detector acceptance ROI。
- 每行表示最终形成有效 detector hit 的 gamma track。`total`、`k1`、`ms` 分别使用 `scatter_count_total >= 1`、`== 1`、`>= 2`。
- target 只由当前 detected track 的 `first_scatter_z` 定义：

\[
\Omega_F:z_{\mathrm{first}}<z_c-5,
\qquad
\Omega_T:z_c-5\le z_{\mathrm{first}}<z_c+5,
\qquad
\Omega_B:z_{\mathrm{first}}\ge z_c+5.
\]

P0 使用对应缺陷深度的相同边界；不使用 first-scatter 横向位置、缺陷三维体积、last scatter 或图像 ROI 分类事件。

slab 通过 `--slab-grid-root` 独立传入，采用相同的 81-pose valid-event 布局。目录根必须包含：

```yaml
reference_type: uniform_pmma_front_slab
thickness_mm: 55.0
vehicle_geometry_file: config/geometry/article_files/P4_front_slab_55mm.yaml
```

文件名为 `reference_manifest.yaml`。`vehicle_geometry_file` 必须与每个 run 的 metadata 完全一致；全部 slab runs 必须使用 P001/S4、560 keV、一个共同的 `vehicle_model_id`、`n_primary` 和几何文件。

## 图像、ROI 与指标

六个互斥基础计数为 `k1_F/k1_T/k1_B/ms_F/ms_T/ms_B`，由它们逐像素构建：

| 方法 | 事件组成 |
|---|---|
| M0 | `k1_all + ms_all` |
| M1 | `k1_all` |
| M2 | `k1_T` |
| M3 | `ms_T` |
| M4 | `k1_T + ms_T` |
| M5 | `k1_T+B + ms_T+B` |

正式计算前验证 `F+T+B=all`、`M0=k1_all+ms_all`、`M4=M2+M3` 和 `M5=M0-I_F`。图像按 metadata 中的物理 `(x,y)` 写入 `[y,x]` 矩阵，不按文件或数组索引猜测坐标。

固定 ROI 为中心 25 点 defect ROI、7.5 mm 环上的 24 点 guard 和 10 mm 外圈的 32 点 background ROI。guard 不参与 CNR；背景标准差使用 `ddof=1`：

\[
\mathrm{CNR}_g=\frac{|\mu_{\mathrm{ROI},g}-\mu_{\mathrm{BG},g}|}{\sigma_{\mathrm{BG},g}},
\qquad
\eta_g=\frac{N_g}{N_{\mathrm{total}}}.
\]

MS 收益比较 M2 与 M4，source-region 收益比较 M1 与 M4，front-source removal 比较 M0 与 M5。CNR 和计数收益分别报告，不合成为单一指标。原始观测点的背景方差或任一收益分母为零时失败。

每个 pose 从六个基础类别进行 5000 次 Poisson 重采样，并由同一组 draws 重建 M0–M5、CNR、保留率和收益；95% 区间取 2.5% 与 97.5% 分位数。抽样中背景标准差为零或参照分母为零时，只将该 draw 排除出相应指标并报告有效抽样数。P4 的同一组 draws 用于全部 P4 产物，slab 独立重采样。参考作差使用

\[
I_{\mathrm{ref},-F}=I_{\mathrm{total}}-\alpha I_{\mathrm{slab}},
\qquad
\alpha=\frac{N_{\mathrm{primary,target}}}{N_{\mathrm{primary,slab}}}.
\]

不从 defect ROI 拟合 \(\alpha\)。

## 输出合同与执行

主网格 core 入口固定生成下列 5 PNG + 3 CSV：E3-F1～F5 与 E3-T1～T3。它执行与严格入口相同的主网格、事件恒等式、CNR、保留率和重采样检查，但不接受 slab，也不创建 E3-F6/E3-T4。

```bash
conda run -n data python -m scripts.postprocessing.e3.run_core \
  --results-root results/articlev3_merged \
  --overwrite
```

slab 数据齐备后，严格 `run.py` 成功时，`results/articlev3_merged/postprocessing/E3/` 根目录恰好包含 6 张 PNG 和 4 张 CSV：

- `E3_F1_P4_S4_M0_M5.png`
- `E3_F2_M1_M4_depth.png`
- `E3_F3_M0_M5_depth.png`
- `E3_F4_all_methods_CNR_depth.png`
- `E3_F5_all_methods_retention_depth.png`
- `E3_F6_front_removal_reference.png`
- `E3_T1_P4_S4_metrics.csv`
- `E3_T2_depth_method_metrics.csv`
- `E3_T3_depth_comparisons.csv`
- `E3_T4_front_removal_reference_metrics.csv`

E3-F1 对应 P4–S4 M0–M5；E3-F2 对应 M1/M4；E3-F3 对应 M0/M5；E3-F4/E3-F5 分别给出全部六种方法的 CNR/保留率深度趋势；E3-F6 给出 M0、M5 与 slab 参考作差。T1 为 P4 六方法表，T2 为 36 行全深度方法表，T3 为 18 行三类策略比较表，T4 为三行前层参考表且不定义“与 M5 的差异”指标。

不生成 PDF、SVG、EPS、单独子图、调试图、表格截图、manifest 或自动 Markdown 报告。所有计算先在 staging 目录完成，只有十文件合同全部通过才原子发布；`--overwrite` 只允许覆盖既有的十个 E3 文件，未知文件会阻止发布。

```bash
conda run -n data python -m scripts.postprocessing.e3.run \
  --results-root results/articlev3_merged \
  --slab-grid-root /path/to/P4_front_slab_55mm_grid \
  --overwrite
```

`--resample-seed` 默认固定为 `20260814`。终端汇报主数据与 slab 目录、81 位姿完整性、逐像素恒等式、目标路径及所有数据问题；当前 `run_core.py` 正常完成，而严格 `run.py` 因缺少 slab 应在创建完整输出前非零退出。
