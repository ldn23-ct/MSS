# E2：缺陷可观测响应与 first-scatter source-region mechanism

## 状态与数据边界

`results/articlev3_merged` 已具有 P0/P1–P6 的完整 matched grid：八个条件各 81 pose、每 pose 100M histories。E2-F1 因而覆盖 P1-S1 至 P6-S6 全部六组 pair，并通过严格验收。

正式单位姿统计使用 `--summary-source grid-zero`，从每组 grid 的 `(0,0)` 读取合并后的 100M 数据；默认 `center` 行为继续保留以兼容旧流程。`--allow-partial-grid` 只供诊断不完整的其他 campaign，不用于本次正式结果。

## 事件、case 与统计口径

- 所有统计读取 `events/valid`，并使用匹配 profile、recorded `slit_label` 和随 pose 平移的闭区间 detector ROI。
- total、k1、ms 分别为 `scatter_count_total >=1`、`==1`、`>=2`，并满足 `total=k1+ms`。
- E2-F2/F3 的选择单位为 `BASELINE:DEFECT:SLIT:SCATTER_CLASS`；defect 为 P1–P6，slit 必须匹配该 defect 深度，scatter class 为 total/k1/ms。
- CLI 可重复传入多个 case，只生成显式选择的组合；完全相同的重复选择失败。默认 case 为 `P0:P4:S4:total`。
- 同一 baseline/defect/slit 的多个 scatter classes 共用一张 E2-T2。
- E2-B/E2-D 及源区占比使用 5000 次 Poisson 重采样；均匀模体与缺陷模体独立抽样，`k1/ms` 为互斥基础计数，`total` 由同一 draw 的 `k1+ms` 重建。95% 区间使用 2.5%/97.5% 分位数，分母为零的 draw 仅对相应指标无效并记录有效抽样数。

F2/F3 与 E2-T2 共用函数参数 `depth_bin_width_mm`。脚本顶部 `DEFAULT_DEPTH_BIN_WIDTH_MM = 2.0` 是默认正式宽度；可修改该默认值，或在 Python 调用 `run_e2(..., depth_bin_width_mm=...)`。宽度必须有限并满足 `0 < width <= 220` mm。

F2 使用覆盖 0–220 mm 的自定义宽度 bins：

\[
C_i^{(s)}=\frac{H_D^{(s)}(z_i)-H_0^{(s)}(z_i)}{H_0^{(s)}(z_i)}.
\]

`H0=0` 的 bin 为 NaN 并在曲线中留空，不置零、不 clipping。`--min-baseline-count N` 可进一步屏蔽 `H0<N` 的 bin；未指定时不引入额外阈值。

对 defect 中心深度 \(z_c\)，F4 自动设置 Target `[zc-5,zc+5)`，Front `[0,zc-5)`，Behind `[zc+5,220]`。先按原始深度精确分区，再在每个 region 中以边界为锚点建立所选宽度的 bins；全深度或 region 长度不能整除时，在末端追加精确 residual bin。区域积分值为：

\[
C_r^{(s)}=\frac{N_{r,D}^{(s)}-N_{r,0}^{(s)}}{N_{r,0}^{(s)}},\qquad
D_{\mathrm{TV},r}^{(s)}=\frac12\sum_{i\in r}|p_{D,r}^{(s)}(z_i)-p_{0,r}^{(s)}(z_i)|.
\]

F4 下 panel 直接绘制每个 bin 的

\[
d_i^{(s)}=\frac12|p_{D,r}^{(s)}(z_i)-p_{0,r}^{(s)}(z_i)|,
\]

并要求每个 region 中 `sum(d_i)` 精确等于 E2-T2 的 DTV。baseline 相对变化分母为零时 fail fast；若某一条件的区域直方图为空，DTV 无法归一化并明确写为 `NA`、`n_effective=0`，不得伪填为零。

## 输出合同

E2-F1、E2-T1 和 E2-T3 使用固定文件名：

- `figures/E2-F1_matched_grid_total_counts.png`：最终 3×4 raw-count grid，pair 内共享 `viridis` scale，不插值；
- `tables/E2-T1_{center|zero_pose}_raw_count_decomposition.csv`：18 行长表，覆盖六个 matched cases × `total/k1/ms`，保存 `N0/ND`、整体相对响应、95% 区间和有效抽样数；
- `tables/E2-T3_{center|zero_pose}_source_region_fractions.csv`：108 行长表，覆盖六个 matched cases × baseline/defect × `total/k1/ms` × F/T/B，保存区域计数、总计数、占比、95% 区间和有效抽样数。正式合并数据使用 `zero_pose` 文件名。

每个选中的 case/class 生成：

- `figures/E2-F2_{BASELINE-SLIT_vs_DEFECT-SLIT}_{class}_binwise_relative_response.png`：单类别 bin-wise response step plot 与零线；
- `figures/E2-F3_{...}_{class}_raw_depth_counts.png`：单 panel baseline/defect raw-count steps 与自动 target band；
- 每个唯一 baseline/defect/slit 生成 `tables/E2-T2_{BASELINE-SLIT_vs_DEFECT-SLIT}_source_region_quantitative.csv`，保持全部 9 行 `scatter_class × region`，保存区域计数、`C_r`、DTV、两类指标的 95% 区间和有效抽样数；
- E2-5/E2-6 不生成正式图片，数值证据统一由 E2-T2 提供。

因此 N 个显式 case/class 选择生成 `1+2N` 张 PNG、全局 E2-T1/E2-T3，以及每个唯一 baseline/defect/slit 一张 E2-T2。默认选择为 3 PNG、3 CSV。CSV 中相对量保存无量纲比值，图中显示百分比；不生成 PDF。

## CLI 与验收

本次正式运行：

```bash
conda run -n data python -m scripts.postprocessing.e2.run \
  --results-root results/articlev3_merged \
  --summary-source grid-zero \
  --case P0:P4:S4:total \
  --case P0:P4:S4:k1 \
  --case P0:P4:S4:ms \
  --resample-seed 20260814 \
  --overwrite
```

多 case 示例：

```bash
conda run -n data python -m scripts.postprocessing.e2.run \
  --results-root results/articlev3_merged \
  --summary-source grid-zero \
  --case P0:P4:S4:total \
  --case P0:P4:S4:ms \
  --case P0:P1:S1:ms \
  --overwrite
```

`--resample-seed` 默认固定为 `20260814`，正式抽样次数固定为 5000。manifest/report 记录所有选择、summary source、阈值、重采样参数、动态输出名、target ranges 和 masked-bin 数。验收核对动态精确文件集合、T1/T2/T3 schema、`total=k1+ms`、源区占比闭合、区间有效样本、无 E2-F4、PNG-only 及 grid pair/pose 状态；当前合并 grid 的正式验收为 `pass`。

bin width 不进入文件名；修改宽度后以相同命令运行会原子覆盖同名 F2/F3 和 E2-T2。实际宽度记录在 manifest/report。需要并排保留多个宽度时，应指定不同 `--output-dir` 或在外部保存前一次结果。
