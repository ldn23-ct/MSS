# E2：缺陷可观测响应与 first-scatter source-region mechanism

## 状态与数据边界

E2 center 数据完整。grid 当前只有 P0/P2/P4/P6 × P001，因此 E2-F1 只有 P2-S2、P4-S4、P6-S6 三组完整 pair；缺少 P0/P1/P3/P5 × P002，共 324 poses。

`--allow-partial-grid` 发布明确标记为 `partial` 的 3×4 预览，S1/S3/S5 panels 显示 unavailable。后处理不得以 center 数据、零值或插值补齐；严格模式在 grid 不完整时发布前失败。

## 事件、case 与统计口径

- 所有统计读取 `events/valid`，并使用匹配 profile、recorded `slit_label` 和随 pose 平移的闭区间 detector ROI。
- total、k1、ms 分别为 `scatter_count_total >=1`、`==1`、`>=2`，并满足 `total=k1+ms`。
- E2-F2/F3/F4 的选择单位为 `BASELINE:DEFECT:SLIT:SCATTER_CLASS`；defect 为 P1–P6，slit 必须匹配该 defect 深度，scatter class 为 total/k1/ms。
- CLI 可重复传入多个 case，只生成显式选择的组合；完全相同的重复选择失败。默认 case 为 `P0:P4:S4:total`。
- 同一 baseline/defect/slit 的多个 scatter classes 共用一张 E2-T2。

F2/F3/F4 与 E2-T2 共用函数参数 `depth_bin_width_mm`。脚本顶部 `DEFAULT_DEPTH_BIN_WIDTH_MM = 2.0` 是默认正式宽度；可修改该默认值，或在 Python 调用 `run_e2(..., depth_bin_width_mm=...)`。宽度必须有限并满足 `0 < width <= 220` mm。

F2 使用覆盖 0–220 mm 的自定义宽度 bins：

\[
C_i^{(s)}=\frac{H_D^{(s)}(z_i)-H_0^{(s)}(z_i)}{H_0^{(s)}(z_i)}.
\]

`H0=0` 的 bin 为 NaN 并在曲线中留空，不置零、不 clipping。`--min-baseline-count N` 可进一步屏蔽 `H0<N` 的 bin；未指定时不引入额外阈值。

对 defect 中心深度 \(z_c\)，F4 自动设置 Target `[zc-5,zc+5)`，Front `[0,zc-5)`，Behind `[zc+5,220]`。先按原始深度精确分区，再在每个 region 中以边界为锚点建立所选宽度的 bins；全深度或 region 长度不能整除时，在末端追加精确 residual bin。区域积分值为：

\[
C_r^{(s)}=\frac{N_{r,D}^{(s)}-N_{r,0}^{(s)}}{N_{r,0}^{(s)}},\qquad
D_{\mathrm{TV},r}^{(s)}=\frac12\sum_{i\in r}|p_{D,r}^{(s)}(z_i)-p_{0,r}^{(s)}(z_i)|.
\]

F4 下 panel 直接绘制每个 bin 的

\[
d_i^{(s)}=\frac12|p_{D,r}^{(s)}(z_i)-p_{0,r}^{(s)}(z_i)|,
\]

并要求每个 region 中 `sum(d_i)` 精确等于 E2-T2 的 DTV。区域计数或 DTV 归一化分母为零时 fail fast。

## 输出合同

E2-F1 和 E2-T1 使用固定文件名：

- `figures/E2-F1_matched_grid_total_counts.png`：最终 3×4 raw-count grid，pair 内共享 `viridis` scale，不插值；
- `tables/E2-T1_center_raw_count_decomposition.csv`：六个 matched cases 的整体 total/k1/ms counts 与相对响应。

每个选中的 case/class 生成：

- `figures/E2-F2_{BASELINE-SLIT_vs_DEFECT-SLIT}_{class}_binwise_relative_response.png`：单类别 bin-wise response step plot 与零线；
- `figures/E2-F3_{...}_{class}_raw_depth_counts.png`：单 panel baseline/defect raw-count steps 与自动 target band；
- `figures/E2-F4_{...}_{class}_source_region_decomposition.png`：两个纵向 panels，分别为 region-anchored bin-wise count response 和 DTV contribution，并标出 Front/Target/Behind；
- 每个唯一 baseline/defect/slit 生成 `tables/E2-T2_{BASELINE-SLIT_vs_DEFECT-SLIT}_source_region_quantitative.csv`，保持 `scatter_class,region,N_r0,N_rD,C_r,D_TV_r` 六列和全部 9 行。

因此 N 个显式 case/class 选择生成 `1+3N` 张 PNG、1 张 E2-T1，以及每个唯一 baseline/defect/slit 一张 E2-T2。默认选择仍为 4 PNG、2 CSV。CSV 中 C 保存无量纲比值，图中显示百分比；不生成 PDF。

## CLI 与验收

当前数据的默认 partial 运行：

```bash
conda run -n data python -m scripts.postprocessing.e2.run \
  --results-root results/articlev2 \
  --case P0:P4:S4:total \
  --allow-partial-grid \
  --overwrite
```

多 case 示例：

```bash
conda run -n data python -m scripts.postprocessing.e2.run \
  --results-root results/articlev2 \
  --case P0:P4:S4:total \
  --case P0:P4:S4:ms \
  --case P0:P1:S1:ms \
  --allow-partial-grid \
  --overwrite
```

manifest/report 记录所有选择、阈值、动态输出名、target ranges 和 masked-bin 数。验收核对动态精确文件集合、T1/T2 schema、`sum(d_i)=DTV`、PNG-only、grid pair/pose 状态；完整 grid 为 `pass`，当前 partial 运行为 `partial`。

bin width 不进入文件名；修改宽度后以相同命令运行会原子覆盖同名 F2/F3/F4 和 E2-T2。实际宽度记录在 manifest/report。需要并排保留多个宽度时，应指定不同 `--output-dir` 或在外部保存前一次结果。
