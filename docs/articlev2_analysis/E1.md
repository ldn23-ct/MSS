# E1：均匀模体系统响应基线与散射空间特征

## 状态、输入与选择

E1 使用审计通过的 P0 center valid events，建立 detector ROI、slit depth selectivity 和 first/last scatter 空间分布三层证据。输入为：

- `events/valid/center/P0/{P001,P002}/**/events_valid.csv` 及同目录 `metadata.yaml`；
- `data_processing/audit/{audit_summary.yaml,condition_inventory.csv}`；
- P002 对应 S1/S3/S5，P001 对应 S2/S4/S6；
- ROI 事件必须同时满足 recorded `slit_label` 和固定闭区间 detector ROI。

所有图只改变展示方式，不删除 valid events。first-scatter depth profile 是 detected source-response，不解释为独立物理 kernel。

## 三图合同

输出根为 `results/articlev2/postprocessing/E1/`，正式结果恰有三张 PNG：

1. `E1-F1_detector_plane_roi.png`
   - 1×2 panels：左侧 P002 的 S1/S3/S5，右侧 P001 的 S2/S4/S6；
   - 每个 panel 只绘制本 acquisition group 的事件、三种 slit 颜色和三组 ROI；
   - ROI 使用浅灰带、边界虚线和顶部直接标签；散点 legend 仅列本组三个 slit；
   - 两 panel 共享 metadata detector-y 范围；各自 x 范围取该组 `det_x` 的 `[0.005,0.995]` quantile 与全部 ROI 边界的并集，再加 3% padding。
2. `E1-F2_roi_conditioned_total_depth_response.png`
   - S1–S6 各自使用对应 ROI 内的 total events；
   - 0–220 mm、2 mm bins，step histogram，各 slit 独立积分归一化为 1；
   - 不绘制 k1/ms，不平滑，设计深度只作轴下标记。
3. `E1-F3_first_last_spatial_comparison.png`
   - 2×2 panels：第一行 P002 的 S1/S3/S5 x-z、y-z，第二行 P001 的 S2/S4/S6 x-z、y-z；
   - first 为低透明度蓝色散点，last 为橙色并置于上层，均 rasterized；
   - 每个 acquisition group 独立由该组 first/last pooled 坐标的 `[0.005,0.995]` quantile 加 3% padding 得到 x/y/z 视窗，同一行共享 z 范围；
   - x/y/z 手动范围逐轴优先于两组自动 quantile；视窗只控制显示，不过滤事件；
   - console、report 和 manifest 按 profile、projection、first/last 记录显示范围外点数，不生成 outlier 图。

E1 不生成常规结果表或 PDF。`analysis_manifest.yaml`、`report.md` 和 `acceptance_summary.yaml` 是控制文件。已有 `roi_sensitivity/` 与 `archive/` 在原子覆盖时保留。

## CLI 与验收

默认运行：

```bash
conda run -n data python -m scripts.postprocessing.e1.run \
  --results-root results/articlev2 \
  --overwrite
```

可选视窗参数：

```text
--spatial-view-quantile LOW HIGH   默认 0.005 0.995
--spatial-xlim LOW HIGH
--spatial-ylim LOW HIGH
--spatial-zlim LOW HIGH
```

验收要求包括：真实 acquisition grouping、S1–S6 ROI 非空、六条 depth profile 各自归一化、F3 每个 panel 的 first/last 输入点数等于对应 profile 的 valid-event 数、精确三图 PNG 合同、无正式 E1 表格和新 PDF。
