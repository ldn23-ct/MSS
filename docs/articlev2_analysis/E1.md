# E1：均匀模体多狭缝深度响应基线

## 状态与目标

E1 已实现。它使用 P0 center 条件验证 S1–S6 的 detected first-scatter depth selectivity；输出是 detected source-response，不解释为独立物理 kernel。

## 输入

- `results/articlev2/events/valid/center/P0/{P001,P002}/**/events_valid.csv`
- 同目录 `metadata.yaml`
- `results/articlev2/data_processing/audit/{audit_summary.yaml,condition_inventory.csv}`，且 E1 状态必须为 `ready`
- 固定 `slit_label` 与 geometry acceptance ROI；不重新从 detector position 分配通道

## 输出与验收

输出根为 `results/articlev2/postprocessing/E1/`：

- `figures/`：detector plane 分布以及 2 mm、4 mm normalized depth response；
- `tables/`：事件计数、深度 profile、peak、design-depth fraction 和 binning comparison；
- `analysis_manifest.yaml`、`report.md`、`acceptance_summary.yaml`。

验收要求包括六个 slit 齐全、`total = k1 + MS`、每组 histogram 归一化为 1、Poisson 字段正确、2/4 mm 输出行数和深度范围符合合同。

```bash
python -m scripts.postprocessing.e1.run --results-root results/articlev2
```
